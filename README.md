# Global spatiotemporal distribution of adiposity-associated disease risk, 2015–2050

Replication code for the manuscript *"Global spatiotemporal distribution of
adiposity-associated disease risk"* (submitted).

This repository contains the complete analysis pipeline: from harmonized
covariates and national BMI anchors, through Bayesian multilevel regression
with poststratification (MRP) and annual 0.1° BMI projections under four SSP
scenarios (2025–2050), to population-attributable fractions (PAFs),
attributable deaths/DALYs for colorectal cancer and 64 further diseases,
historical GBD benchmarking, and all main and supplementary figures.

## Repository contents

```
code/
  config/                     central path configuration (paths.py / paths.R) and R package installer
  s00_setup/                  study-spec freeze, directory scaffold, data-gate validators
  s01_input_inventory/        input audit (data completeness and format checks)
  s02_covariate_gates/        Gate B (future-covariate audit), Gate C (harmonized covariates),
                              full-covariate extension (PM2.5, NTL, urbanicity, built-up)
  s03_national_bmi_anchors/   national BMI-7-category anchors, 2025–2050 (204 territories)
  s04_mrp_model/              future-capable MRP: D1 reduced-demography fit, full-covariate
                              refit, non-inferiority gates, Stan program
  s05_historical_bmi/         temporal backtesting (Gate D); historical 25+ re-export, 2015–2024
  s06_future_bmi_production/  annual 0.5°/0.1° BMI-7 production, 4 SSPs × 2025–2050,
                              multiscale delivery (0.1°/0.5°/ADM1), bridge sensitivity
  s08_crc_paf/                colorectal-cancer PAF (WCRF/AICR primary RR), national + grid
  s09_crc_burden/             CRC attributable deaths/DALYs, 2025–2050, four SSPs
  s10_gbd_benchmark/          historical benchmark vs GBD 2021 official estimates, 2015–2021
  s11_all_disease_extension/  65-disease extension: harmonize GBD inputs, RR crosswalk,
                              national + 0.1° PAF, burden benchmark, spatial density allocation
  s12_figures/                all main-text and supplementary figures (final versions)
  s16_web_export/             export of the lightweight JSON/WebP data behind the interactive explorer
docs/
  PIPELINE.md                 stage-by-stage reproduction guide
  DATA.md                     external data sources and where to place them
  index.html / app.js / style.css / data/ / maps/
                              interactive results explorer (serve docs/ with GitHub Pages)
```

An interactive results explorer (BMI and high-BMI-attributable disease
burden, 2015–2050, maps + national trends) lives in `docs/` — enable GitHub
Pages with source `docs/` to publish it at `https://<user>.github.io/<repo>/`.
It is regenerated by `code/s16_web_export/export_web_data_v1.py`.

Note: stage s07 (RR freeze for CRC) is a data-only step; the frozen RR table
is described in docs/DATA.md. Stage numbering follows the manuscript's
analysis order; s13/s14 (tables, uncertainty) are generated by the figure
scripts directly.

## System requirements

- OS: Windows 10/11 (primary development platform) or Linux/macOS
- Python ≥ 3.10 (3.11 recommended)
- R ≥ 4.3 with CmdStan ≥ 2.33 (only required for the MRP refit in s04)
- Disk: ~250 GB for the full 0.1° production (intermediate COGs); the
  summarized national-level products need <5 GB
- RAM: ≥ 32 GB recommended for 0.1° raster stages

## Installation

```bash
# Python environment
conda env create -f environment.yml        # or: pip install -r requirements.txt
conda activate bmi-burden

# R packages (from the repository root)
Rscript code/config/install_packages.R
# then once, for the Bayesian MRP stage:
Rscript -e "cmdstanr::install_cmdstan()"
```

## Instructions for use

1. Download the external input data listed in **docs/DATA.md** and place them
   under `data/` exactly as documented there.
2. Run the pipeline stages in order (`s00` → `s12`) following
   **docs/PIPELINE.md**. Every script reads its inputs from, and writes its
   outputs to, the roots defined in `code/config/paths.py` / `paths.R`;
   nothing is written outside the repository.
3. All figures are produced by the scripts in `code/s12_figures/` (see the
   figure-to-script map in docs/PIPELINE.md).

Path roots can be overridden with environment variables
(`BMI_PROJ_ROOT`, `BMI_DATA_ROOT`, `BMI_RESULTS_ROOT`) without editing any
script.

## Data availability

All input data are from public sources (GBD 2021, GBD Foresight, NCD-RisC,
IIASA SSP, CMIP6, ERA5, ISIMIP, WorldPop, GHS, Natural Earth, WCRF/AICR);
download links and query parameters are given in docs/DATA.md. Pipeline
outputs are regenerated by the scripts and are not tracked in this
repository.
